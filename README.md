# 大富翁 寶島風雲

仿《大富翁 11》風格的網頁版大富翁，加入參考 **Fortune Street（富豪街）** 的區域股票系統。
純 HTML / CSS / JavaScript，不需安裝任何套件。

## 開始玩

直接用瀏覽器打開 `index.html` 即可（支援電腦與手機）。Three.js 已放在 `vendor/`，離線也能玩。

也可以開一個本機伺服器：

```bash
npx serve .
# 或
python3 -m http.server
```

- 1～4 位玩家，每位可設定為真人或電腦；全部設為電腦即可觀戰
- 8 位經典角色：阿土伯、孫小美、錢夫人、金貝貝、沙隆巴斯、忍太郎、大老千、烏咪
- 每天開始時自動存檔（localStorage），可從標題畫面「繼續上次遊戲」
- 空白鍵／Enter 可以擲骰子、按確定

## 🗺️ 地圖

| 地圖 | 路線 |
| --- | --- |
| 🏝️ 寶島台灣 | 環島一周：基隆、宜蘭、花蓮、台東、高雄、台南、台中、台北 |
| 🗾 日本列島 | 東京出發：北關東、東北、日本海、山陰、九州、瀨戶內、關西、東海道（有富士山） |
| 🇰🇷 韓半島 | 首爾出發繞半島：春川、江原、慶北、釜山、全南、全羅、忠清、首都圈，濟州島在海上 |

所有地圖共用同樣的 44 格配置與地價階梯，只有地名、區域、股票與 3D 地形不同。
新增地圖只要在 `js/maps.js` 加一筆：島嶼類用 `coast` 模式（道路沿海岸內縮），跨海或大陸類用 `route` 模式（道路依城市座標連成一圈，跨海處自動填出堤道）。

## 🏙️ 3D 地圖

仿《大富翁 11》的 3D 視角：
- 依真實經緯度畫出陸地與道路，每格的地名對應它在地圖上的實際位置
- 山脈（玉山、富士山、喜馬拉雅山有雪頂）、森林、淺海、帆船、雲朵、鵝鑾鼻燈塔
- 土地上的建築隨等級長高：插旗空地 → 平房 → 洋房 → 公寓 → 大樓 → 摩天樓，屋頂是地主顏色
- 銀行、醫院、神明廟、監獄、道具店、證券所、新聞台、摩天輪（小遊戲）等地標
- 地圖上漂浮的神明、路障與地雷，棋子一格一格跳著前進
- 鏡頭自動跟隨目前玩家；拖曳旋轉、滾輪或雙指縮放，「全景」俯瞰全島
- 直接點選 3D 地圖上的格子或建築查看資訊、選擇卡片目標
- 可隨時切換回平面棋盤（不支援 WebGL 的裝置會自動使用平面棋盤；手機直向時平面棋盤為 8×16 直式排列）

## 遊戲系統

### 🏠 土地與建築
- 44 格環狀地圖，每張地圖 8 個區域
- 空地可購買；停在自己的土地可升級：平房 → 洋房 → 公寓 → 大樓 → 摩天樓
- 同區擁有越多土地，過路費越高；整區全包再加成
- 地主住院或坐牢時收不到過路費
- 現金不足時自動提款 → 賣股票 → 變賣土地，仍不足則破產

### 🃏 卡片（26 種）
| 類型 | 卡片 |
| --- | --- |
| 移動 | 遙控骰子、停留卡、轉向卡、烏龜卡、冬眠卡 |
| 道路 | 路障、地雷、機器娃娃 |
| 金錢 | 均富卡、均貧卡、查稅卡、搶奪卡、免費卡 |
| 土地 | 購地卡、換地卡、怪獸卡、天使卡、惡魔卡、漲價卡、查封卡 |
| 股票 | 紅卡（連漲）、黑卡（連跌） |
| 神明 | 請神符、送神符 |
| 攻擊 | 陷害卡、飛彈卡 |

停在「卡片」格免費獲得，或到「道具店」用點券購買。擲骰前可使用，每回合限 1 張。

### ⛩️ 神明（11 位）
地圖上會隨機出現神明，經過即被附身數回合；也可到神明廟擲筊請神。

- 好神：大財神、小財神、大福神、小福神、土地公、天使
- 壞神：大窮神、小窮神、大衰神、小衰神、惡魔

### 📈 股票（參考 Fortune Street）
- 每個區域發行一檔股票，股價 = 區域開發價值 × 市場係數
- 在該區買地、蓋房會推升股價
- 一次買賣滿 10 股會推動股價漲跌
- 有人在該區付過路費時，所有股東依持股數領取股利（由銀行支付）
- 股價每天隨機波動；紅卡、黑卡、新聞事件會造成連續漲跌
- 平日擲骰前可進入股市，週末休市；停在「證券所」週末也能交易，還能打聽內線消息

### 🎮 小遊戲（7 種）
打地鼠、賽馬、猜大小、拉霸機、記憶翻牌、神準一擊、猜拳王

### 其他
- 機會、命運各 12 種事件；新聞 13 種全體事件（地價上漲、股市崩盤、颱風、地震、神明出巡……）
- 交通工具：步行（1 顆骰）、機車（2 顆）、汽車（3 顆），擲骰前可自選顆數
- 銀行：經過領薪水與點券，停留可存提款，每月 1 日存款生息

## 程式結構

| --- | --- |
| `js/data.js` | 角色、卡片、神明、經濟參數 |
| `js/maps.js` | 地圖資料：區域、地名、股票、海岸線、道路路線、山峰 |
| `js/game.js` | 回合流程、移動、格子事件、每日結算、存檔 |

| `js/stocks.js` | 股票系統與股市介面 |
| `js/cards.js` | 卡片目標選擇與效果 |
| `js/gods.js` | 神明附身、神明廟擲筊 |
| `js/events.js` | 機會、命運、新聞 |
| `js/minigames.js` | 7 種小遊戲 |
| `js/shop.js` | 道具店 |
| `js/ai.js` | 電腦玩家決策 |
| `js/ui.js` | 平面棋盤、對話框、選取格子、2D/3D 切換 |
| `js/map3d.js` | 依地圖資料建立陸地、道路、格子位置；建築與地標模型 |
