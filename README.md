# 大富翁 寶島風雲

仿《大富翁 11》風格的網頁版大富翁，加入參考 **Fortune Street（富豪街）** 的區域股票系統。
純 HTML / CSS / JavaScript，不需安裝任何套件。

## 開始玩

直接用瀏覽器打開 `index.html` 即可（支援電腦與手機，手機直向時棋盤會自動改為 8×16 直式排列）。

也可以開一個本機伺服器：

```bash
npx serve .
# 或
python3 -m http.server
```

- 1～4 位玩家，每位可設定為真人或電腦；全部設為電腦即可觀戰
- 8 位經典角色：阿土伯、孫小美、錢夫人、金貝貝、沙隆巴斯、忍太郎、大老千、烏咪
- 每天開始時自動存檔（localStorage），可從標題畫面「繼續上次遊戲」
- 空白鍵／Enter 可以擲骰子、按確定

## 遊戲系統

### 🏠 土地與建築
- 44 格環狀地圖，8 個區域：基隆、宜蘭、花蓮、台東、高雄、台南、台中、台北
- 空地可購買；停在自己的土地可升級：平房 → 洋房 → 公寓 → 大樓 → 摩天樓
- 同區擁有越多土地，過路費越高；整區全包再加成
- 地主住院或坐牢時收不到過路費
- 現金不足時自動提款 → 賣股票 → 變賣土地，仍不足則破產

### 🃏 卡片（26 種）
| 類型 | 卡片 |
| --- | --- |
| 移動 | 遙控骰子、停留卡、轉向卡、烏龜卡、冬眠卡 |
| 道路 | 路障、地雷、機器娃娃 |
| 金錢 | 均富卡、均貧卡、查稅卡、搶奪卡、免費卡 |
| 土地 | 購地卡、換地卡、怪獸卡、天使卡、惡魔卡、漲價卡、查封卡 |
| 股票 | 紅卡（連漲）、黑卡（連跌） |
| 神明 | 請神符、送神符 |
| 攻擊 | 陷害卡、飛彈卡 |

停在「卡片」格免費獲得，或到「道具店」用點券購買。擲骰前可使用，每回合限 1 張。

### ⛩️ 神明（11 位）
地圖上會隨機出現神明，經過即被附身數回合；也可到神明廟擲筊請神。

- 好神：大財神、小財神、大福神、小福神、土地公、天使
- 壞神：大窮神、小窮神、大衰神、小衰神、惡魔

### 📈 股票（參考 Fortune Street）
- 每個區域發行一檔股票，股價 = 區域開發價值 × 市場係數
- 在該區買地、蓋房會推升股價
- 一次買賣滿 10 股會推動股價漲跌
- 有人在該區付過路費時，所有股東依持股數領取股利（由銀行支付）
- 股價每天隨機波動；紅卡、黑卡、新聞事件會造成連續漲跌
- 平日擲骰前可進入股市，週末休市；停在「證券所」週末也能交易，還能打聽內線消息

### 🎮 小遊戲（7 種）
打地鼠、賽馬、猜大小、拉霸機、記憶翻牌、神準一擊、猜拳王

### 其他
- 機會、命運各 12 種事件；新聞 13 種全體事件（地價上漲、股市崩盤、颱風、地震、神明出巡……）
- 交通工具：步行（1 顆骰）、機車（2 顆）、汽車（3 顆），擲骰前可自選顆數
- 銀行：經過領薪水與點券，停留可存提款，每月 1 日存款生息

## 程式結構

| 檔案 | 內容 |
| --- | --- |
| `js/data.js` | 角色、地圖、卡片、神明、經濟參數 |
| `js/game.js` | 回合流程、移動、格子事件、每日結算、存檔 |
| `js/economy.js` | 購地、蓋房、過路費、付款、破產、銀行 |
| `js/stocks.js` | 股票系統與股市介面 |
| `js/cards.js` | 卡片目標選擇與效果 |
| `js/gods.js` | 神明附身、神明廟擲筊 |
| `js/events.js` | 機會、命運、新聞 |
| `js/minigames.js` | 7 種小遊戲 |
| `js/shop.js` | 道具店 |
| `js/ai.js` | 電腦玩家決策 |
| `js/ui.js` | 棋盤繪製、對話框、選取格子 |
| `js/main.js` | 開始畫面與設定 |
